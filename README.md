# Focusly

시험일까지 남은 기간, 공부 가능한 시간, 과목별 난이도와 강의자료 분량을 바탕으로 일자별 학습 계획을 자동 생성하는 AI 학습 플래너 프로토타입입니다.

## 프로젝트 개요

시험을 준비할 때 과목마다 난이도와 학습량이 다르기 때문에 계획을 세우는 데 많은 시간이 필요합니다. Focusly는 사용자가 시험 정보와 과목, 강의자료를 입력하면 학습·복습·문제풀이 일정을 자동으로 배치하여 체계적인 시험 준비를 돕습니다.

## 주요 기능

- 시험 이름과 시험일 설정
- 평일 및 주말 공부 가능 시간 설정
- 학습 목표 선택
- 과목별 난이도 등록
- PPT, PDF, Word, 한글, TXT 강의자료 업로드
- 자료 개수와 용량을 활용한 예상 학습량 계산
- 과목 난이도와 목표를 반영한 공부 계획 생성
- 개념 학습, 취약 개념 복습, 문제풀이, 오답 정리 자동 배치
- 시험 전날 최종 점검 일정 제공
- 입력 정보 브라우저 자동 저장
- PC 및 모바일 화면 지원

## 실행 방법

1. 저장소에서 `index.html` 파일을 내려받습니다.
2. 내려받은 `index.html` 파일을 더블클릭합니다.
3. Chrome 또는 Edge 등의 웹 브라우저에서 프로그램이 실행됩니다.
4. 시험 정보와 과목을 입력하고 강의자료를 등록합니다.
5. **AI 공부 계획 만들기** 버튼을 눌러 일자별 계획을 확인합니다.

별도의 프로그램 설치나 서버 실행은 필요하지 않습니다.

## 작동 방식

현재 버전은 웹 브라우저에서 실행되는 프로토타입입니다. 업로드한 문서의 실제 본문을 AI가 읽는 방식이 아니라 파일 개수와 용량, 과목 난이도, 목표 및 남은 기간을 기준으로 예상 학습량을 계산합니다.

실제 문서 내용을 정밀하게 분석하려면 향후 서버 기반 문서 분석 기능과 AI API 연동이 필요합니다.

## 기대 효과

- 시험 계획을 세우는 시간 절약
- 과목별 난이도에 따른 균형 있는 학습
- 복습과 문제풀이 누락 방지
- 사용 가능한 시간에 맞춘 현실적인 일정 관리
- 체계적인 자기주도 학습 습관 형성

## 향후 개선 사항

- PDF 및 PPT 본문 분석
- 과목과 강의자료 자동 연결
- 일정 완료 여부 체크 기능
- 학습 진행률 시각화
- 계획 수정 및 내보내기
- 실제 AI 모델 연동
