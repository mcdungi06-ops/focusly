# Focusly

시험일과 강의자료를 바탕으로 맞춤 공부 계획을 생성하는 AI 학습 플래너 프로토타입입니다.

## 주요 기능

- 시험일과 학습 가능 시간 설정
- 과목별 난이도 등록
- PPT, PDF, Word, 한글, 텍스트 강의자료 업로드
- 자료 분량과 과목 난이도를 반영한 학습량 계산
- 개념 학습, 복습, 문제풀이, 시험 전날 점검의 일자별 자동 배치
- 모바일 화면 지원

## 실행 방법

`index.html` 파일을 내려받아 웹 브라우저로 열면 바로 실행됩니다.

> 현재 버전은 브라우저에서 동작하는 프로토타입입니다. 실제 문서 본문을 AI로 정밀 분석하려면 서버 기반 문서 분석 기능을 추가해야 합니다.
